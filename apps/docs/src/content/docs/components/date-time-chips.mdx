```sh
npx @eoria/cli add date-time-chips
```

Needs `@react-native-community/datetimepicker`, a native module. Expo projects add it with `npx expo install @react-native-community/datetimepicker` and rebuild the development build. The item also brings `chip` and `date-picker`, whose formatter and Android dialog it shares, and through them `dialog`, `button` and `text`.

## Usage

```tsx
import { DateTimeChips, type DateTimeChipsSection } from '@/components/ui/date-time-chips'
import { Calendar, Clock } from 'lucide-react-native'

const [start, setStart] = useState(() => new Date())

<DateTimeChips
  value={start}
  onValueChange={setStart}
  minimumDate={new Date()}
  timeZoneName="Europe/Lisbon"
  minuteInterval={5}
  dateIcon={<Calendar />}
  timeIcon={<Clock />}
>
  <Text variant="muted">Times are in Lisbon time.</Text>
</DateTimeChips>
```

Children sit under the chips and above the open picker. Use them for a note the user should read while picking, such as the time zone.

Open a picker from somewhere else with `expanded` and `onExpandedChange`:

```tsx
const [expanded, setExpanded] = useState<DateTimeChipsSection | null>(null)

<DateTimeChips
  value={start}
  onValueChange={setStart}
  expanded={expanded}
  onExpandedChange={setExpanded}
/>
<Button variant="link" onPress={() => setExpanded('time')}>Change the time</Button>
```

## Your own layout

`DateTimeChips` puts the chips in a row, then its children, then the picker. When the chips belong somewhere else, such as beside a label in a form row, build it from the parts. `DateTimeChipsRoot` holds the value and the open section and takes the same props as `DateTimeChips`, without the icons. Put a `DateTimeChipsTrigger` for each section and one `DateTimeChipsPicker` anywhere inside it.

```tsx
import {
  DateTimeChipsPicker,
  DateTimeChipsRoot,
  DateTimeChipsTrigger,
} from '@/components/ui/date-time-chips'
import { HStack, VStack } from '@/components/ui/stack'
import { Calendar, Clock } from 'lucide-react-native'

<DateTimeChipsRoot value={start} onValueChange={setStart} minuteInterval={5}>
  <HStack gap={3}>
    <Clock size={24} color={theme.colors.mutedForeground} />
    <VStack flex={1} gap={1}>
      <Text variant="muted">Starts</Text>
      <HStack gap={2}>
        <DateTimeChipsTrigger
          section="date"
          icon={<Calendar />}
          styles={{ root: { flexGrow: 1, justifyContent: 'center' } }}
        />
        <DateTimeChipsTrigger section="time" icon={<Clock />} />
      </HStack>
    </VStack>
  </HStack>
  <Text variant="muted">Times are in Lisbon time.</Text>
  <DateTimeChipsPicker />
</DateTimeChipsRoot>
```

The date chip grows to fill the row and the time chip keeps its width. The picker spans the root, so it is as wide as the whole form row, not the column the chips sit in. The root resizes with the same layout transition as `DateTimeChips`.

## The open chip

The open chip takes Chip's selected look. To change it, set the `chipSelected`, `chipLabelSelected` and `chipIconSelected` slots. They apply only while a chip is open and merge after every other chip style, so they win over `chip`:

```tsx
<DateTimeChips
  value={start}
  onValueChange={setStart}
  dateIcon={<Calendar />}
  timeIcon={<Clock />}
  styles={{
    chip: { backgroundColor: theme.colors.muted },
    chipSelected: { backgroundColor: theme.colors.accent, borderColor: theme.colors.primary },
    chipLabelSelected: { color: theme.colors.foreground },
    chipIconSelected: { color: theme.colors.primary },
  }}
/>
```

## Props

| Prop                                              | Values                                                  | Default           |
| ------------------------------------------------- | ------------------------------------------------------- | ----------------- |
| `value`, `onValueChange`                          | `Date`, controlled                                      |                   |
| `expanded`, `defaultExpanded`, `onExpandedChange` | `date`, `time` or `null`, controlled or uncontrolled    | `null`            |
| `minimumDate`, `maximumDate`                      | `Date`                                                  |                   |
| `locale`, `timeZoneName`, `is24Hour`              | as on [Date Picker](/components/date-picker/)           | device            |
| `minuteInterval`, `display`                       | as on [Date Picker](/components/date-picker/)           |                   |
| `dateLabel`, `timeLabel`                          | read out before each value, and the label of its picker | `Date`, `Time`    |
| `formatDate`, `formatTime`                        | `(date) => string`                                      | `formatDateValue` |
| `dateIcon`, `timeIcon`                            | element taking `size` and `color`                       |                   |
| `variant`, `size`                                 | as on [Chip](/components/chip/)                         | `filled`, `md`    |
| `disabled`                                        | boolean, closes the open picker                         | `false`           |
| `children`                                        | content between the chips and the picker                |                   |
| `chipStyles`                                      | Chip's own slots for both chips, such as `body`         |                   |
| `styles`                                          | override the slots below                                |                   |

`DateTimeChipsRoot` takes every prop above except `dateIcon`, `timeIcon` and `chipStyles`. Its `children` are the parts and your own layout.

`DateTimeChipsTrigger` takes `section`, `date` or `time`, and the props of [Chip](/components/chip/) except `children`, `value`, `selected`, `onDismiss` and `dismissLabel`. `icon` sets its icon. `variant` and `size` default to the root's. `styles` holds Chip's own slots. `onPress` runs after the chip opens or closes its picker.

`DateTimeChipsPicker` takes View props. It renders nothing while no chip is open, and nothing on Android.

The slots are `root`, `chips`, `chip`, `chipLabel`, `chipIcon`, `dateChip`, `timeChip`, `chipSelected`, `chipLabelSelected`, `chipIconSelected` and `picker`. `chips` is the row `DateTimeChips` draws; with the parts you lay the row out yourself.

## Notes

The value is one `Date`. The date chip changes its day and the time chip its time, and every pick calls `onValueChange` straight away. There is no Done button, unlike Date Picker, because the picker sits in the page and the chips already show the result.

Pressing a chip opens its picker and closes the other. Pressing the open chip closes it. On iOS the date opens the system calendar and the time opens the wheels, inline under the children. The picker fades in over 150 ms and the component resizes with a layout transition, as Collapsible does. Views below it jump unless they set `layout` themselves. Both animations follow the system's reduce motion setting. On Android there is no inline picker, so a chip opens the system dialog and the chip stays open until the dialog closes. If Android refuses to open the dialog, for example between Activities, the chip closes as if the user had dismissed it. The Android time dialog has no bounds, so the picked instant is clamped to `minimumDate` and `maximumDate` before `onValueChange`, as in [Date Picker](/components/date-picker/#bounds).

`display.ios` replaces the style of both pickers, so `spinner` turns the calendar into wheels too.

The time zone, locale and clock behave as on [Date Picker](/components/date-picker/#time-zone-locale-and-clock). In short, `timeZoneName` reaches both the picker and the chip text, `is24Hour` reaches the chip text and the Android dialog, and the iOS wheels take their clock from `locale`.

Each chip is a button whose label is its name and its value, for example "Date, Sep 24, 2026", with an `expanded` state. The open chip also takes Chip's selected look. The picker follows the chips and the children in reading order and carries the chip's name as its label. The labels default to English. Pass `dateLabel` and `timeLabel` to translate them.

The `chip`, `chipLabel` and `chipIcon` slots go to each Chip's `root`, `label` and `icon`. A chip's root merges `chip`, then `dateChip` or `timeChip`, then the trigger's own `styles.root` or `chipStyles.root`, then `chipSelected` while open. The label and the icon follow the same order. The label uses tabular digits so the chip keeps its width as the time changes. Set `chip` to `{ flexGrow: 1, justifyContent: 'center' }` to let both chips fill the row, or set `dateChip` alone to let only the date grow.
