Components and blocks have no version numbers. You copy the source, so the registry always
serves the newest file and `npx @eoria/cli diff <name>` shows how your copy differs. This page
lists what was added or changed and when. The packages have their own pages:
[`@eoria/core`](/changelog/core/) and [`@eoria/cli`](/changelog/cli/).

## 2026-10-04

### Changed

- [Toast](/components/toast/) takes an `icon` per toast, shown before the title and hidden
  from screen readers. It sizes and colours itself from a new `icon` slot unless the element
  sets its own `size` or `color`.
- `Toaster` takes `dismissHint`, the screen-reader hint for tapping a toast, so it can be
  translated. The default is still `"Dismisses this notification"`.
- A toast action closes the toast before it calls `onPress`, so an `onPress` that throws no
  longer leaves the toast up. The action has a `hitSlop` that brings its 36pt height to 44pt.
- Each toast is announced once. Under Strict Mode the announcement used to run twice.
- [Chip](/components/chip/) takes `labelProps` for its string label, such as
  `{ numberOfLines: 1 }`. [Date Time Chips](/components/date-time-chips/) triggers pass it on.
- [Tabs](/components/tabs/) forgets the layout of a trigger that unmounts and hides the
  indicator while no mounted trigger has the active value. Before, removing the selected last
  tab left the indicator where that tab had been.
- [Swipeable](/components/swipeable/) no longer writes a ref during render, so a copied
  `swipeable.tsx` passes the `react-hooks/refs` lint rule. Actions behave as before.
- On Android, a [Date Picker](/components/date-picker/) in `datetime` closes when the time
  dialog throws before it opens, and every mode closes when `onValueChange` throws. Before,
  both left the field open with no dialog on screen.
- Components that dim or fill a slot only in a disabled, pressed, selected or open state now
  set the resting value in the base slot, for example `opacity: 1` on Button's `root`. The
  look does not change. Unistyles reapplies the styles a view had during a theme change, and
  a key the next style leaves out could keep its old value, so a button disabled during a
  theme switch could stay dimmed after it was enabled. Affected: Accordion, Action Sheet,
  Button and Icon Button, Card, Checkbox, Chip, Collapsible, Date Picker, Dropdown Menu,
  Input with Input Group, Textarea and Password Input, Input OTP, Item, Radio Group, Rating,
  Select with Combobox, Select Sheet, Slider, Stepper, Swipeable, Switch, Tabs, and Toggle
  with Toggle Group.

## 2026-10-03

### Added

- [Select Sheet](/components/select-sheet/), a select whose options open in a bottom sheet.
  Single or multiple, with local or server search, a create row for the search text, and a
  ref to open it from your own rows.
- [Date Time Chips](/components/date-time-chips/), a date chip and a time chip that open the
  platform picker inline beneath them, with room for a note between the chips and the picker.

### Changed

- [Date Picker](/components/date-picker/) takes `locale`, `timeZoneName`, `is24Hour`,
  `minuteInterval` and `display` and passes them to the native picker. The default text
  follows the same locale, zone and clock, and `formatDateValue` is exported.
- Date Picker clamps the picked instant to `minimumDate` and `maximumDate`. The Android time
  dialog has no bounds, so a time before the minimum could get through before.
- On iOS, a value the parent changes while the Date Picker dialog is open replaces the draft,
  so Done no longer commits the value from when the dialog opened.
- Date Picker is controlled whenever the `value` key is present, as Select and Combobox are.
  Setting a controlled value back to `undefined` or `null` now clears the field. Before, the
  last picked date came back.
- A controlled [Stepper](/components/stepper/) steps from the parent's value. A parent holding
  `value={4}` that ignores changes got 5, 6, 5 from plus, plus, minus, and now gets 5, 5, 3.
  A held button reads the current `min`, `max`, `step` and `disabled` on every tick, so it
  stops at a bound the parent narrowed during the hold. The file no longer touches a ref
  during render.
- [Button](/components/button/) and [Icon Button](/components/icon-button/) keep a caller's
  `accessibilityState.busy`. Before, `busy: true` without `loading` was announced as not busy.
- [Select Sheet](/components/select-sheet/) `createAction` takes `alwaysShow`, which keeps the
  create row when the query matches an option's label, for records that can share a name.
- [Date Time Chips](/components/date-time-chips/) comes apart into `DateTimeChipsRoot`,
  `DateTimeChipsTrigger` and `DateTimeChipsPicker`, so the chips and the picker can sit in
  different containers, such as chips beside a label and the picker under the whole row.
  `DateTimeChips` renders as before and is now built from them.
- Date Time Chips has slots for the open chip, `chipSelected`, `chipLabelSelected` and
  `chipIconSelected`, which win over `chip`. Before, styling `chip` also restyled the open chip.
  `dateChip` and `timeChip` style one chip, `chipIcon` reaches the icons, and `chipStyles`
  reaches Chip's own slots such as `body`.
- [Password Input](/components/password-input/) takes `InputGroupAddon` children, such as a
  lock icon at the start, and `showIcon` and `hideIcon` to replace the eyes.
- [Tabs](/components/tabs/) no longer reads a ref during render, so a copied `tabs.tsx` passes
  the `react-hooks/refs` lint rule. The indicator moves as before.
- On Android, [Date Picker](/components/date-picker/) and Date Time Chips close when the system
  dialog fails to open, for example between Activities. Before, the field stayed open and
  could not open again. `openAndroidPicker` calls `onDismiss` in that case and takes an
  optional `onError`.

## 2026-09-22

### Added

- Commerce blocks: [Product detail](/blocks/product-detail/), [Filter sheet](/blocks/filter-sheet/)
  and [Paywall](/blocks/paywall/). Account: [Edit profile](/blocks/edit-profile/). Social:
  [Chat thread](/blocks/chat-thread/) and [Feedback form](/blocks/feedback-form/). Between them
  they use Sheet, Carousel, Rating, Stepper, Accordion, Chip, ToggleGroup, Slider, RadioGroup,
  Select, DatePicker, Textarea and Empty, which no block used before.
- Guides for [overlays](/guides/overlays/), [loading, empty and error states](/guides/states/)
  and [navigation](/guides/navigation/).

## 2026-09-19

### Added

- Blocks, whole screens you add like a component. Auth: [Sign in](/blocks/sign-in/),
  [Sign up](/blocks/sign-up/), [Verify OTP](/blocks/verify-otp/),
  [Forgot password](/blocks/forgot-password/) and [Reset password](/blocks/reset-password/).
  App: [Settings screen](/blocks/settings-screen/), [Profile header](/blocks/profile-header/),
  [Onboarding](/blocks/onboarding/), [Transaction list](/blocks/transaction-list/),
  [Checkout summary](/blocks/checkout-summary/) and [Inbox](/blocks/inbox/).
- Actions and overlays: [Icon Button](/components/icon-button/),
  [Alert Dialog](/components/alert-dialog/), [Action Sheet](/components/action-sheet/) and
  [Sheet](/components/sheet/).
- Forms: [Input Group](/components/input-group/), [Password Input](/components/password-input/),
  [Search Bar](/components/search-bar/), [Date Picker](/components/date-picker/),
  [Stepper](/components/stepper/), [Rating](/components/rating/),
  [Toggle Group](/components/toggle-group/) and [Chip](/components/chip/).
- Lists and display: [Item](/components/item/), [Swipeable](/components/swipeable/),
  [Collapsible](/components/collapsible/), [Carousel](/components/carousel/),
  [Empty](/components/empty/) and [Image](/components/image/).
- Platform: [Keyboard](/components/keyboard/) and [Haptics](/components/haptics/).

### Changed

- [Button](/components/button/) takes `loading`. It shows the platform spinner in place of the
  icon, blocks presses and keeps its colours.
- Error text, invalid borders and destructive menu rows use the new `destructiveText` colour, so
  they stay readable in dark mode. Update `@eoria/core` to 0.2.0 before you update Alert,
  Field, Input, Select, Input OTP, Date Picker, Action Sheet or Dropdown Menu.
- [Date Picker](/components/date-picker/) takes `open`, `defaultOpen` and `onOpenChange`, and
  the iOS calendar fills the dialog.

## 2026-09-18

### Changed

- Every component reads its corner radius, control height, border width, shadow and typeface
  from the theme, so a preset changes the shape of the components as well as the colours.
  Needs `@eoria/core` 0.2.0. See [Theming](/start/theming/).
