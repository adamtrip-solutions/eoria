A theme is a plain object of colours, sizes and fonts. Every component reads its styles from
that object, so one change reaches every component that uses the value. You do not write the
object from nothing. You start from a preset.

## Pick a preset

A preset is a complete look: a light palette, a dark palette, the corner radii, the control
heights and a typeface. `@eoria/core` ships six. Pick one, then copy the line that uses it or
the whole object.

<PresetTabs />

`createThemes` turns a preset into the `light` and `dark` themes Unistyles needs, and adds the
spacing and type scales every preset shares. The code goes in the `src/unistyles.ts` file that
`init` wrote.

`zinc` and `moss` use the system font. `cobalt`, `iris`, `tide` and `plum` name a typeface that
your app has to embed, and fall back to the system font until it does. [Fonts](/start/fonts/)
shows how.

## Change a preset

You rarely need the whole object. Spread a preset and replace the parts you want.

Your brand colour on the main button, in both modes:

```ts
import { configureUnistyles, createThemes, presets } from '@eoria/core'

const brand = {
  ...presets.zinc,
  light: { ...presets.zinc.light, primary: '#0f62fe', primaryForeground: '#ffffff' },
  dark: { ...presets.zinc.dark, primary: '#78a9ff', primaryForeground: '#0a0a0a' },
}

configureUnistyles({ themes: createThemes(brand) })
```

Pill buttons and fields, shorter controls, outlined cards:

```ts
const brand = {
  ...presets.zinc,
  radius: { ...presets.zinc.radius, control: 9999 },
  control: { sm: 36, md: 44, lg: 52 },
  stroke: 1,
}
```

Check the contrast of a new `primary` against `primaryForeground`. The shipped pairs pass WCAG AA
for the 16pt button label. [Tokens](/start/tokens/) lists every key and what it drives.

## Light, dark, and system

The app follows the OS appearance by default. To let the user pick, turn adaptive themes off
first. Calling `setTheme` while they are on throws.

```ts
import { UnistylesRuntime } from 'react-native-unistyles'

export function setMode(mode: 'system' | 'light' | 'dark') {
  if (mode === 'system') {
    UnistylesRuntime.setAdaptiveThemes(true)
    return
  }
  if (UnistylesRuntime.hasAdaptiveThemes) UnistylesRuntime.setAdaptiveThemes(false)
  UnistylesRuntime.setTheme(mode)
}
```

`useUnistyles().rt.themeName` and `rt.hasAdaptiveThemes` re-render when either changes, so a
segmented control bound to them stays in sync.

## Switch preset while the app runs

Update both registered themes in place. The light and dark switch keeps working and nothing
remounts.

```ts
import { UnistylesRuntime } from 'react-native-unistyles'

const themes = createThemes(presets.cobalt)
UnistylesRuntime.updateTheme('light', (t) => ({ ...t, ...themes.light }))
UnistylesRuntime.updateTheme('dark', (t) => ({ ...t, ...themes.dark }))
```
